# Cricket App 🏏

A DBMS-based Cricket Management Web Application developed using PHP, MySQL, HTML, CSS, JavaScript, and XAMPP.

## 📌 Features

- User Registration & Login
- Team Management
- Player Records
- Match Scheduling
- Score Tracking
- Admin Panel
- Database Integration using MySQL
- Responsive Web Interface

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP
- GitHub

## 🗄️ Database

The project database file is included:

```text
myapp.sql
```

Import it using phpMyAdmin or MySQL Workbench.

---

## ⚙️ Setup Instructions

### 1. Install XAMPP
Start:
- Apache
- MySQL

### 2. Clone Repository

```bash
git clone https://github.com/edoctrams/cricket_app.git
```

### 3. Move Project Folder

Place the project inside:

```text
htdocs/
```

### 4. Import Database

- Open phpMyAdmin
- Create database
- Import `myapp.sql`

### 5. Run Project

Open browser:

```text
http://localhost/cricket_app
```
